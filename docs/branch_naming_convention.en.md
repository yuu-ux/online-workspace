# Branch Naming Convention

Branch names must follow the format below.

```text
type/three-digit-issue-number-description
```

## type

- `feature/`: Add a new feature
- `modify/`: Change an existing feature
- `fix/`: Fix a bug
- `refactor/`: Refactor code
- `docs/`: Add or modify documentation
- `test/`: Add or modify tests

## Naming Rules

- Include the issue number as three digits (for example, `002`).
- Use lowercase English letters for the description, separating words with hyphens (`-`).
- Do not use spaces, Japanese characters, uppercase letters, or underscores (`_`).

## Examples

```text
feature/123-add-user-profile
fix/005-fix-login-validation
docs/072-add-branch-naming-convention
```
