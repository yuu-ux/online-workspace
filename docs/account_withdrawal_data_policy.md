# 退会時のデータ保持方針

## 退会直後

- `users.deleted_at` に退会日時を記録する。認証時は必ず `deleted_at IS NULL` のユーザーだけを検索するため、退会済みアカウントはログインできない。
- 対象アカウントの全 HTTP session を失効させ、現在の session を破棄して SecurityContext をクリアする。
- 参加中のルームから退出し、進行中の作業セッションを退会日時で終了する。
- 未使用の招待トークンを無効化する。
- 退会 API では誤操作防止のためパスワードの再入力を必須とする。影響の確認画面はフロントエンドの退会画面実装時に扱う。
- 退会後も登録データを保持し、自動削除・匿名化は行わない。
