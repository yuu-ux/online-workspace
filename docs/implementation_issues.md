# 実装Issue分解

## 目的

このファイルは、要件定義と画面遷移図から実装完了までの差分をissue単位に分解するためのバックログである。

必達issueをすべて完了した状態を、2026年7月10日リリース目標に対する実装完了とみなす。

## 前提

- 要件定義: `docs/requirements.md`
- 画面遷移図: `docs/screen_wireframe.drawio`
- 実装方針: `docs/plan.md`
- API設計はOpenAPIを採用する
- OpenAPI仕様をバックエンドとフロントエンドの契約として扱う
- 既存MVPは参考実装および移植元として扱う

## 優先度

- P0: 完了しないとアプリとして成立しない
- P1: 最終版必達機能
- P2: 提出品質、運用、余力対応

## 完了条件の共通ルール

各issueは以下を満たしたら完了とする。

- 要件に対応する実装がある
- 画面またはAPIから動作確認できる
- 必要なDBマイグレーションがある
- 必要なバリデーションと認可チェックがある
- 主要な正常系と異常系のテストがある
- READMEまたは関連docsの更新が必要な場合は反映済み
