# MVP

- ユーザー登録
- ユーザーログイン
- ルーム作成
- 複数人の音声通話


# 機能要件

- 認証
    - ログイン
    - ユーザー登録
- オンラインスペース
    - スペースの作成
        - 人数制限
        - 誰でも入れる
- 記録
    - 作業時間
- タイマー機能
    - ポモドーロみたいな
- 作業目的でない人を除く機能
- 作業メンバー一人一人の音量調節機能(discordにあるっぽい)
- ランダムマッチングではなく、部屋を開放して誰でも入れる形にするのがいいかも。
- 部屋を作成する時に似てる部屋と統合する機能とかもおもしろいかも。
    - 各部屋のジャンルを設定できるようにしたい

# 作成ページ

- ユーザー
    - 登録
    - ログイン
    - マイページ
        - ユーザー情報の編集
- スペース一覧(トップページ)
- スペース作成画面
- スペース詳細
